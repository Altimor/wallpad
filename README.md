# Wallpad

Scan a QR code on an office TV and your phone becomes a remote for the Mac behind it.

On the TV's Mac, run:

```bash
curl -fsSL https://github.com/Altimor/wallpad/releases/latest/download/install.sh | bash
```

Then turn on Wallpad in Privacy & Security → Accessibility, print the QR card from the Desktop and stick it on the TV.
Phones need to be on the same Wi‑Fi. The first time, type the code shown on the TV.
